# My eWPTX Journey

After spending a lot of time learning web application security, I decided to take on the **eWPTX** certification.

This wasn't just another certification for me. I wanted to test whether I could take everything I'd learned about web applications, APIs, authentication, JavaScript, and penetration testing and actually apply it under pressure.

## Why I Chose eWPTX

My main interest has always been **web security**.

I enjoy understanding how applications work, breaking down their logic, finding weaknesses, and figuring out why those weaknesses exist in the first place.

The eWPTX felt like a good challenge because it focuses heavily on practical web application penetration testing rather than simply memorizing vulnerabilities.

## Preparation

My preparation focused mainly on areas that I knew would be important during a real web application assessment.

I spent time working on:

- Web application penetration testing
- API security
- Authentication and authorization
- Access control
- JWT and session security
- JavaScript security
- Client-side vulnerabilities
- Server-side vulnerabilities
- Reconnaissance and enumeration
- Common injection vulnerabilities
- SSRF
- NoSQL injection
- API testing

One of the biggest things I learned during preparation was that knowing a vulnerability in theory isn't enough.

You need to understand **how the application works**.

> Understanding how an application works is more valuable than memorizing payloads.

## The Exam

When I finally started the exam, I knew it wasn't going to be about simply throwing payloads at an application and hoping something worked.

The interesting part was the investigation.

You have to observe how the application behaves, understand the architecture, follow the data, test different assumptions, and continuously adapt your approach.

The exam was challenging, but it was also **a lot of fun**.

## What I Learned

A payload is just a tool.

The real skill is understanding **where to use it, why it might work, and what the application's behavior is telling you**.

As a developer, you learn how applications are built.

As a security researcher, you learn how those applications can fail.

Being able to look at both sides gives you a much better understanding of web security.

## The Result

After all the preparation and the exam itself, I was happy to finally have **eWPTX** completed.

For me, this isn't the end of the journey.

It's another step.

## What's Next?

More labs.

More research.

More development.

More write-ups.

And hopefully a lot more interesting bugs along the way.

**eWPTX done. The journey continues.** 🚀 -->
